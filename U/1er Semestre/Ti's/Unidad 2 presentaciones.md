# Medios de transmisión
Son dispositivos que permiten la conexion a la red y transmitir cualquier mensaje a cualquier lado del mundo.

1. Modem: Convierte señales analogicas a digitales y viceversa, se conecta de forma almbrica por medio de fibra optica para hacer llegar la red.
2. Router. es un dispotitivo que permite a varios dispositivos conectarse a una sola red
3. Hub. Es un dispotitivo qye tiene entradas y salidas USB o HDMI su objetivo es compartir datos a todos los dispotivos de forma alambrica
4. Switch. Centraliza de forma similar al **HUB** pero de forma mas logica y puede ccubrir mas distancia
5. Repeater. Es un dipositivo que toma una señal para hacerla mas fuerte y hacerla llegar mas lejos, es mas eficiente ayuda a tener mas alcance a una red
6. Bridge. Conecta dos tipos de redes distintas para hacerlas funcionar como una sola, su principal tarea es filtras y redirigir informacion
7. Access Point. Se encargan de conectar diferentes dispositivos a una sola red de forma inalambrica o a cableado pero en estos es mas eficiente la conexcion
8. gateaway
9. server. se trata de un dispotitivo computacional de alto rendimiento y capacidad, creado especificamente para gestionar.
10. Terminal. es un dispotivo de uso individual o laboral que facilita la interaccion del usuario
11. Adapter. Este dispotivo permite conectarse a una red local LAN, por medio de una conexcion 
12. Infrared node
13. Antenas. Son dispotivos que emiten y reciben ondas electromagneticas de readiofrecuencia para direccionarlas a largas distancias.
	1. Dipolo y polo
	2. Panel plano
	3. Yagi
	4. Parabolica
14. Satelites artificiales. Amplifican y transmiten informcion a traves del planeta a una gran velocidad. Son no guiados y tienen un alcance global por medio.
